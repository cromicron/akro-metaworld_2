## Overview

This fork of [Akro](https://github.com/rlworkgroup/akro) includes minor modifications to ensure compatibility with **Gymnasium** and **Metaworld 2** environments. Akro is a Python library designed to simplify handling and manipulation of action and observation spaces, commonly used in reinforcement learning.
It has been used in my [Master Thesis Constrained Meta Reinforcement Project](https://github.com/cromicron/garage-for-thesis)

## Key Changes

- Adjustments for compatibility with [Gymnasium](https://github.com/Farama-Foundation/Gymnasium)
- Updates for integration with [Metaworld 2](https://github.com/Farama-Foundation/Metaworld)

## Installation

To download and install this version of Akro, run the following command:

```bash
pip install git+https://github.com/cromicron/akro.git
```

Or, if you want to clone and install manually:

```bash
git clone https://github.com/cromicron/akro.git
cd akro
pip install .
```
